# Hapa App

Flutter mobile application for Hapa.

## Responsibilities

- Flutter iOS and Android application
- Map-first nearby Flash experience
- Authentication screens and secure token handling
- Flash reporting and multi-photo selection
- Verification and freshness UI
- Offline feed cache and report queue
- Categories, modes, filters, saved places, and notifications

## Repository boundary

This repository contains Flutter frontend code only. The PHP backend and administration system live in `alumasinde/hapa-api`.
